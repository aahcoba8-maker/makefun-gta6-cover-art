# TROPIC HEAT Cover Studio

An offline, single-page cover editor that turns local photos and captions into original sunset and neon poster art.

## Features

- Seven layouts: Keyart, Band, Slash, Grid 6, Trio, Full, and Story.
- Six color grades, including Poster Ink, Sunset, Neon, Golden, Noir, and Clean.
- Per-panel photo selection, crop positioning, zoom, and grade override.
- Editable cover lettering, sticker options, grain, vignette, and gutters.
- PNG export in wide (1920 × 1080), square (1080 × 1080), or portrait (1080 × 1350), with an export-all option.

## Run locally

```sh
node serve.ts
```

Open [http://localhost:8080](http://localhost:8080) in a desktop browser. The app loads all code, fonts, and sample photos from `app/` and makes no network requests.
